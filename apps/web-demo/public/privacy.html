Zupulse Privacy Notice

Last updated: 2026-08-14

Zupulse is a local-first score viewer and practice workspace. Your scores, file names, paths, practice data, and edits stay on your device.

Optional anonymous telemetry

Distributed Browser and Desktop builds may send optional anonymous application events and sanitized JavaScript error reports to PostHog Cloud US. Events use a random installation identifier and an application-session identifier. They contain release, platform, runtime, locale, and allowlisted semantic event fields.

Zupulse does not send score content, titles, artists, file names, paths, library identifiers, URLs, DOM text, user input, diagnostics files, or crash dumps. Autocapture, session replay, person profiles, and GeoIP enrichment are disabled. The ingestion service may receive network information required to deliver a request; see PostHog's own privacy documentation for its processing details.

Your choice

Telemetry is enabled by default in distributed builds and is introduced by a first-run notice. You can close it there or use “Privacy & diagnostics” in the application header at any time. Turning it off stops future requests and removes the local anonymous installation identifier. Re-enabling creates a new identifier.

Contact

For questions or changes, open an issue in the Zupulse repository.
