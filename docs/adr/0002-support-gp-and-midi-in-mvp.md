# ADR 0002：第一版同时支持 GP 与 MIDI

## 状态

已接受

> 后续说明：ADR 0036 将 MusicXML 导入安排在 GP 与 MIDI 分析之间；本 ADR 对 MIDI 的产品范围仍然有效，但不再定义紧邻 Desktop GP Slice 的交付顺序。

## 背景

产品定位不是单一 Guitar Pro viewer，也不是单一 MIDI 工具，而是跨端练习型 viewer。研究报告指出，GP 与 MIDI 是两个性质不同的问题：GP 是结构化乐谱文件，MIDI 是演奏事件流。

如果只做 GP，第一版风险更低，但产品差异化不足。如果承诺任意 MIDI 生成高质量钢琴谱，第一版风险过高。

## 决策

第一版采用 GP + MIDI 双优先。

GP 第一版目标：

- 支持 `.gp3`、`.gp4`、`.gp5`、`.gpx`、`.gp`。
- 查看 Tab / 五线谱。
- 播放、变速、循环、mute / solo、轨道控制。
- 当前小节或音符高亮跟随。

MIDI 第一版目标：

- 支持 `.mid`、`.midi`。
- 提供可靠 piano-roll。
- 提供基础钢琴谱。
- 支持量化粒度。
- 支持左右手自动分配。
- 标记重叠音、疑似错误量化和不可漂亮转谱的小节。
- 支持小节级修正或重算。

## 后果

正面影响：

- 产品从第一版起覆盖吉他、贝斯、钢琴和多乐器练习者。
- MIDI piano-roll + 基础钢琴谱形成差异化。
- GP 与 MIDI 可以共享播放、练习、sidecar 和同步能力。

负面影响：

- MIDI Analyzer 会显著增加第一版复杂度。
- 基础钢琴谱质量需要清晰设边界。
- 测试素材需要覆盖两类格式。

## 非目标

第一版不承诺任意复杂 MIDI 一键生成出版级钢琴谱。

第一版不做完整制谱编辑器。
