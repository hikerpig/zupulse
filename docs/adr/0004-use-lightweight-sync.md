# ADR 0004：第一版采用轻量同步

## 状态

已接受

## 背景

产品需要在 macOS 与 iOS 之间保持连续练习体验，但第一版不希望承担完整云曲库、版权风险、存储成本和复杂同步冲突。

用户可以通过本地文件、iCloud Drive、AirDrop 或系统文件能力获得原始谱文件。App 只需要让练习状态、批注和轻编辑结果跟随用户。

## 决策

第一版只同步元数据，不同步原始谱文件。

同步范围：

- sidecar。
- 收藏。
- 最近打开。
- 练习进度。
- section。
- 批注。
- track override。
- tempo、transpose、loop 设置。
- MIDI 量化参数、左右手分配和小节级修正。

## 后果

正面影响：

- 降低版权和存储风险。
- 第一版同步模型更小。
- 离线仍然完整可用。
- 与内容指纹 sidecar 方案匹配。

负面影响：

- 新设备上没有原始谱文件时，无法直接打开完整内容。
- 用户需要理解“同步练习数据，不同步谱文件”的边界。
- 文件重定位和手动关联体验需要做好。

## 后续

完整云库、分享链接、教育曲库或机构内容管理可以作为后续阶段评估，不进入第一版核心范围。
