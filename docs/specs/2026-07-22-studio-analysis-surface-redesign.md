# Studio 分析工作区重设计

## 背景

当前 Studio 页面信息密度低，核心分析工作流被低频设置区挤压，片段列表纯文字展示难以快速扫描状态。

## 目标

提升信息密度，让分析片段的标注、核对、修正成为绝对视觉中心，减少文字阅读量，加速决策。

## 改动范围

仅 `StudioPage` 分析区域（右侧 pane），不涉及乐谱预览（左侧）。

---

## 1. 设置与试听区折叠

### 现状

分析设置（分析范围、标注目标）和片段试听（播放、速度、循环、位置滑块）以折叠面板形式占据右侧上半部分约 40% 垂直空间。

### 方案

- **移除 SETTINGS 和 PREVIEW 折叠面板**
- 在命令栏右侧增加两个 icon button：
  - ⚙️ 设置（分析范围 + 标注目标 popup）
  - 🔊 试听（播放控制 popup，含播放/暂停、位置滑块、速度、循环）
- Popup 点击外部或按 Escape 关闭
- 设置 popup 中分析范围默认折叠，标注目标默认展开（更常用）

### 验收

- 默认状态下分析区域上方只显示命令栏，片段列表从顶部开始
- 两个 popup 均可正常打开/关闭/操作
- 原有功能（播放、循环、速度调节、分析范围修改）全部保留

---

## 2. 片段列表视觉编码

### 现状

每个片段以纯文字按钮展示：和弦名 + "第N小节·来源·置信度"灰色小字。311 个片段中快速定位未解决/低置信度片段困难。

### 方案

每个片段卡片改为紧凑行，包含：

| 元素   | 展示方式                                                                                      |
| ------ | --------------------------------------------------------------------------------------------- |
| 和弦名 | 主文字，15px，加粗                                                                            |
| 来源   | 左侧 4px 色条：用户修正（珊瑚色 `#f26b4f`）、算法结果（灰 `#9e9a95`）、来源谱（蓝 `#5dade2`） |
| 置信度 | 右侧圆点：高（绿 `#1f8254`）、中（黄 `#ffbe1a`）、低（红 `#c42814`）                          |
| 位置   | 小节号，12px，灰色，前置 🎵 图标                                                              |
| 状态   | "未解决" 时整行背景加 `#f26b4f` 10% 底色，文字保持可读                                        |
| 选中   | 左侧色条宽度从 4px → 3px + 右侧 2px 珊瑚色边框（避免左右同时加宽导致跳动）                    |

片段行高从当前约 48px 压缩到 40px，padding 从 10px 14px 改为 8px 12px。

### 验收

- 一眼可区分用户修正/算法/来源谱
- 一眼可区分高/中/低置信度
- 未解决片段在列表中足够显眼
- 选中态不导致布局跳动
- Dark 主题下颜色对比度保持

---

## 3. 命令栏重构

### 现状

平铺 6 个等宽按钮：撤销修正、重做修正、重新分析、**立即保存**、导出标注曲谱

### 方案

```
[状态文本]                    [↩️ 撤销] [↪️ 重做] [⟳ 重新分析] [保存 ▼] [⋮ 更多]
```

- 撤销/重做：图标按钮，disabled 时 40% 透明度
- 重新分析：文字按钮，分析中变为「取消分析」+ loading 态
- 保存：主按钮（珊瑚色），下拉菜单含「导出标注曲谱」
- 更多菜单：包含当前不常用的操作（如批量重置等预留）

### 验收

- 命令栏在 960px 宽度下不换行
- 保存按钮视觉权重最高
- 所有原有功能可用

---

## 4. 片段列表空间扩展

### 现状

片段列表固定 220px 宽度，和弦编辑区占据剩余空间。311 个片段的列表很窄，而和弦编辑表单大部分时候不需要手动构建。

### 方案

- 片段列表最小宽度 260px，最大宽度 380px，用户可拖拽调整
- 结构化和弦编辑默认折叠，点击「手动构建」展开
- 默认展开时显示：候选列表 + 快速操作（N.C. 标记、重置）

### 验收

- 片段列表可拖拽调整宽度
- 结构化和弦编辑默认折叠
- 折叠/展开状态记忆在当前 session（不持久化）

---

## 5. 全局进度条

### 方案

在片段列表顶部、过滤器下方添加迷你统计栏：

```
全部 311  |  ● 未解决 23  |  ● 用户修正 145  |  ● 算法结果 143
```

- 统计项可点击，点击后自动切换到对应过滤状态
- 圆点颜色与片段卡片来源色条一致

### 验收

- 统计数字实时更新
- 点击统计项正确切换过滤器

---

## 6. 乐谱联动（可选，本次不做）

点击片段时乐谱自动滚动到对应小节位置。需要 alphaTab API 支持，评估成本较高，放后续迭代。

---

## 排除范围

- 不改左侧乐谱预览区布局
- 不改和弦候选算法逻辑
- 不增加新的分析功能
- 不改动 Studio 页面之外的路由和组件

## 风险

- 颜色编码依赖色觉，需保持文字标签作为降级（已满足）
- 折叠结构化和弦编辑可能影响已习惯手动构建的用户 → 加记忆态缓解

## 验证

- Light / Dark 主题切换检查
- 窄屏（< 960px）回退为上下结构时检查
- 键盘操作（Tab、Enter、Escape）检查
