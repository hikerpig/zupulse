# 测试素材

本目录只存放用于开发和验收的谱文件，不属于 Desktop Shell 或 Browser Demo 的发布资源。

- `Treasure.gp5`：项目负责人已确认可用于本仓库测试；当前仅作为 GP5 多轨候选样本，实际验收结果仍需记录。

GP 准入验收可以从 `Treasure.gp5` 派生项目自有的现代 `.gp` 与中文元数据 fixture；损坏文件应在测试运行时截断合法 fixture 动态生成，不提交额外二进制副本。派生素材只用于最小准入验证，不能替代独立来源的完整格式兼容矩阵。

新增素材必须记录来源与使用许可。来源或授权不明确的文件不得提交，也不得进入自动化 fixture 或应用构建产物。
