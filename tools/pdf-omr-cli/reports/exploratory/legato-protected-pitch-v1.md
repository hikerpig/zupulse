## 为什么允许这四个改动

本轮没有将源谱弧线分类为 tie。`curve_audit.py` 的端点证据仍只提供“可能连接”，包括可能是 slur 的路径。
索引 28 的源谱连接端点位于 C5 与 A♭3；四个待修改音符及其修改前后自然音级均不在本小节的保护集合中。
这些音符自身也没有预测 tie，源谱调号和变音作用域均唯一。

| 事件（上谱表索引 28，voice 3） | 修改前 | 修改后 |
| ------------------------------ | ------ | ------ |
| e1                             | F3     | B♭4    |
| e2                             | E♭3    | A♭4    |
| e3                             | D3     | G4     |
| e4                             | C3     | F4     |

生成器遍历两曲全部谱表小节，没有硬编码索引 28 或四个事件 ID。仍使用冻结的 rank 对应、调号及变音携带规则，
只允许 `writtenPitch` 与相应 `soundingMidi` 改变。恢复这两个字段后，全曲与基线深相等；另行核对两曲所有带 tie 的完整事件，均深相等。

## 保护规则与局限

为了计算提议，临时副本暂不携带预测 tie；这是绕过旧函数的小节级拒绝，不是修改最终结果。
如果提议涉及任何原有带 tie 的事件，拒绝整段；否则恢复全部原 tie。源谱可能连接的自然音级及八度也受到保护，修改前后任一音高落入集合就拒绝。
这种按音级保护比逐事件端点归属更保守，可能额外挡住同音的无关事件，本轮不扩大范围。

所有源谱非唯一、未解析或不支持的曲线路径，若包围框与本小节符头范围相交，则拒绝本小节。
局部范围向左右扩展两个谱线间距、上下扩展一个间距；空符头区域也拒绝。几何窗口和路径来源均在生成前冻结。
这只是受支持向量 PDF 的局部保护假设，不是任意字体、扫描页、裁剪页边或所有曲线编码的完整性证明。

没有依据“未找到端点”推断无 tie，也没有清除跨小节变音状态。score-4 下谱表索引 81 即使附近没有未知曲线，
仍因 B3 的变音解释不唯一而保持 `uncertain-source-alter`，没有修改。
